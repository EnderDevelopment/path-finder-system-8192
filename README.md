# Path Finder System

Teleport to players with a simple GUI input.

## Features

- GUI input for player name
- Tween effect for smooth teleportation

## Requirements

- FiveM server
- ESX framework

## Installation

1. Download the script
2. Place the script in your FiveM server's resources folder
3. Add `start path-finder-system` to your server.cfg

## Usage

1. Type `/pathfinder` in the chat
2. Enter the player's name in the GUI
3. The player will teleport to the target player with a tween effect

## Configuration

- `Config.TweenTime`: Time in milliseconds before tweening to the target location
- `Config.DefaultCoords`: Default coordinates if no player is found
- `Config.GUI`: GUI settings including title, subtitle, and button text
